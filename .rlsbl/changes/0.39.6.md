## 0.39.6

A home project's check stops reporting the assembled site's links

<details>
<summary>Context</summary>

The previous release let a home project's site-level directives resolve, which made its check reach the links those regions render -- links into other projects' subtrees that only the assembled site holds. The resolution check now takes the elements a build does not answer for, so a project exempts its regions and the assembly, where those links must resolve, exempts nothing.

</details>

### Fixes

- **A home project's own check stops reporting the assembled site's links.** The links a site-level directive's region renders address other projects' subtrees and the site-level blog, which the project carrying the region never writes; `selfdoc check` reported every one of them as unresolvable. They are left to the assembly's own pass over the whole tree, which is where they resolve.
