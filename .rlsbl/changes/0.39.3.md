## 0.39.3

The assembly commands name the branch they read and write

<details>
<summary>Context</summary>

Four call sites passed an empty branch into the GitHub Git Data API helpers,
which renders "/repos/<repo>/git/ref/heads/" and is answered 404. It surfaced
on 0.39.2's own post-release hook: the fix that made the hook pin the deploy
workflow to the released version could not take effect, because the command
doing the pinning never reached the assembly at all. The helpers now refuse an
empty branch by name, so the path can no longer be rendered.

</details>

### Fixes

- **The assembly commands reach the assembly again.** `assembly sync-workflow`, `assembly retire` and `post publish` named no branch when they read or wrote the assembly repository, so each failed with `get HEAD ref: gh: Not Found (HTTP 404)` -- a missing argument reported as a missing repository. This is what stopped 0.39.2's post-release hook from pinning the deploy workflow to the version it had just released.
